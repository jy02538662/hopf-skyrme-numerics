## 1. 与断点 2 的关系

| 断点 2 交付 | 能否接入 2.5 |
|-------------|--------------|
| V1 PASS：\(K,M\) 线性响应 | 否（不进引力） |
| V2 WEAK：通量双通道 | 否 |
| V3/V4：\(k_{\mathrm{ex}}\) 非拓扑常数 | **否**；不得把 \(k_{\mathrm{ex}}\) 当作 \(\kappa_t\) |

2.5 使用的刚度/密度耦合来自 **§G + \(\kappa_\rho\) 标定**，不是 Berry 交换响应。

## 2. 冻结字典（阶段 1 唯一合法输入）

| 符号 | 操作定义 | 备注 |
|------|----------|------|
| \(\mathbf n\) | `nfield (N,N,N,3)`，\(\|n\|=1\) | 网格 `linspace(-L,L,N)`，`h=2L/(N-1)` |
| \(\chi\) | \(\sqrt{n_x^2+n_y^2}\) | 横向振幅 |
| \(\rho_{\mathrm{eff}}\) | \(\kappa_\rho\,\chi^2\) | **不用** \(\|\mathbf b\|\) 或能量密度（阶段1） |
| \(\kappa_\rho\) | \(E\big/\int\chi^2\,d^3x\) | 与 `kappa_rho_calibration.py` 同式；积分用 **同一** \(h\) |
| \(\Phi\) | \(\nabla^2\Phi = 4\pi G_{\mathrm{eff}}\,\rho_{\mathrm{eff}}\)，边界 \(\Phi\big|_{\partial}=0\) | \(G_{\mathrm{eff}}\) 为码单位扫描参数 |
| \(\kappa_{\mathrm{eff}}(\mathbf r)\) | \(\kappa_0\bigl(1+2\Phi(\mathbf r)/c^2\bigr)\) | 默认 \(c^2=1\)；要求 \(\|2\Phi/c^2\|\ll 1\) 才称弱场 |
| 微观 \(a,b\) | FS 两项全局刚度 | 变刚度阶段：仅 **\(a\to a(\mathbf r)=\kappa_{\mathrm{eff}}\)**（\(b\) 暂不变） |

## 3. 阶段 1 置信边界（再强调）

- 只做：**提 \(\Phi\)**、验远场是否像 \(1/r\)、**单次** \(\kappa_{\mathrm{eff}}\)、短弛豫/重加权能量对比。  
- **不**声称自洽迭代、不声称 GR、不声称由 \(k_{\mathrm{ex}}\) 导出。  
- 拉普拉斯相未过、远场“精确”未闭合：远场只作 **\(A/r\) 代理检验**。

## 4. 阶段 1 验收表（交付）

1. \(G_{\mathrm{eff}}\) 一组下的 \(\Phi(r)\) 壳平均 + 幂律 \(\alpha_\Phi\)  
2. \(\kappa_{\mathrm{eff}}\) 的 min/max/弱场违反分数 \(\mathrm{frac}(|2\Phi|>0.1)\)  
3. 修正前/后（重加权或短弛豫）：\(E\)、粗估核心半径、\(Q_H\)（若可算）  
4. 定性：是否立即塌缩/爆炸（能量发散或 \(Q\) 崩）
